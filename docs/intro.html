Analisis Exploratorio

Chapter 2 EDA

El Análisis Exploratorio de Datos o EDA (Exploratory Data Analysis) es una etapa fundamental dentro del proceso de análisis estadístico, cuyo propósito es examinar, resumir y comprender las características principales de un conjunto de datos antes de aplicar técnicas de modelado o inferencia formal.

La base de datos utilizada en el presente informe corresponde al conjunto de datos California Housing (housing.csv), el cual contiene información socioeconómica y geográfica recopilada a partir del censo de California de 1990. El conjunto está compuesto por 20,640 observaciones y 10 variables, que describen tanto características demográficas de la población como atributos de las viviendas en cada zona.

El propósito de este trabajo es realizar un Análisis Exploratorio de Datos (EDA) sobre esta base, con el fin de comprender el comportamiento de la variable median_house_value (valor medio de las viviendas), la cual constituye nuestra variable de estudio central, así como su relación con las demás variables predictoras disponibles.

2.1.2 Imputacion de datos faltantes

 data %>%  #datos
  mutate(across( #columnas
    where(is.numeric), #seleccionar variables numericas
    ~ ifelse(is.na(.),mean(.,na.rm=TRUE), .) #si hay un na, reemplazar, si no, dejar la variable
  )) -> df #data limpiada
