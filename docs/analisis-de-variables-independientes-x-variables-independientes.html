Analisis Exploratorio de datos (Exploratory Data Analysis) de California Housing

Chapter 6 Analisis de variables independientes x variables independientes

6.1 Paquete GGally

df %>% 
  ggpairs()+
  theme_bw()

El gráfico permite observar la distribución y dispersión de las diferentes variables del conjunto de datos. Se pueden identificar algunas variables con distribuciones concentradas en determinados rangos, mientras que otras presentan una mayor dispersión de sus valores. También se observan posibles valores atípicos en algunas variables, representados por puntos alejados de la mayor concentración de datos.

6.2 Graficos de variables independientes vs variables independientes

Antes de evaluar la relación de cada variable con median_house_value (nuestra variable respuesta), es necesario examinar cómo se relacionan entre sí las propias variables independientes (predictoras). Este paso, llamado análisis de multicolinealidad, tiene como propósito identificar si dos o más variables predictoras están mostrando la misma información, lo cual puede generar redundancia, distorsionar la interpretación de un futuro modelo de regresión, einflar la capacidad explicativa aparente que deberian proporcionar estas variables.
